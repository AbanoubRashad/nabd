What every Nabd device shares

Open protocolsMQTT 5 over TLS, a published topic contract and JSON payloads. Any broker or platform can read them.
Offline memory5,000 readings kept in flash during a Wi-Fi drop, replayed in order with their original timestamps.
Secure by defaultPinned broker certificate, a unique key per device and firmware that must carry a valid signature.
Remote updatesTwo firmware slots. A new version is kept only after the node checks in; otherwise it rolls back.
Readable on the boxA small screen shows readings, connection state and the last command, so a technician needs no phone.
Safe when aloneRelays switch off if the link is lost for too long, and a watchdog restarts a stuck node.
