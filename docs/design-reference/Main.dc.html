Engineering

The hard parts, solved on purpose

01

No reading is lost

Offline readings are buffered in flash and replayed with their original time. Ingest ignores duplicates by sequence number.

02

Commands you can trust

Every switch shows sent, delivered and confirmed by the device, or a clear timeout. Never a button that pretends.

03

Alerts without spam

Rules wait out short spikes, clear with a margin so they can't flap, and respect a cool-down and quiet hours.

04

Updates can't brick a box

Signed firmware goes to the spare partition and is kept only if the node checks in. Otherwise it rolls back.

Security

A device can only speak for itself

Connected equipment is a way into a network. Nabd treats every node as untrusted until it proves who it is.

  • Encrypted end to endTLS on MQTT, HTTPS and WebSocket. Nothing travels in plain text.
  • One key per deviceBroker rules let each node publish and listen only under its own topic.
  • Signed firmwareA node refuses any update that isn't signed with the release key.
  • Every action loggedWho switched what, when, and what the device answered.
