# EMQX configuration

| File | Mounted at | What |
| --- | --- | --- |
| `base.hocon` | `/opt/emqx/etc/base.hocon` | Built-in database authentication (PBKDF2-SHA256), file ACL, 4 KB packet cap |
| `acl.conf` | `/opt/emqx/etc/nabd-acl/acl.conf` | Topic ACL keyed on the authenticated username |
| `secrets/users.csv` | `/opt/emqx/etc/nabd/users.csv` | Bootstrap users, generated by `pnpm credentials` (gitignored) |

## Accounts

- **Devices** `nabd-01` … `nabd-12`: one password each. A device may publish only `telemetry`, `status` and
  `cmd/ack`, and subscribe only to `cmd` and `ota`, all under `nabd/v1/+/{its own id}/`.
- **`svc-ingest`**: subscribes to telemetry and status (shared subscription `$share/ingest/…`). No publish.
- **`svc-api`**: subscribes to telemetry, status and acks for WebSocket fan-out; publishes `cmd` and `ota`.
- Anything else is denied, and a denied client is disconnected.

The simulator connects as each simulated device with that device's own credentials, so it is held to the
same ACL as real hardware.

EMQX imports `users.csv` at start-up and skips users that already exist. After adding a device, run
`pnpm credentials` and restart EMQX (`docker compose -f infra/docker-compose.yml restart emqx`).
